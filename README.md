# AWS Bastion Host + Private EC2 Architecture

## Project Overview
Implemented a secure AWS cloud networking setup using:

- Bastion Host
- Private EC2 Server
- SSH tunneling
- Linux administration
- Git & GitHub version control

## Architecture
Laptop → Bastion Host → Private EC2 Server

## AWS Services Used
- EC2
- VPC
- Security Groups
- SSH

## Linux Commands Practiced
- ssh
- ip addr
- hostname
- pwd
- ls -la
- sudo apt update

## Outcome
Successfully connected to a private EC2 instance through a bastion host and documented the setup using GitHub.
